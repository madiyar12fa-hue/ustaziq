# USTAZIQ — Мұғалімнің ақылды AI көмекшісі

Бұл нұсқада әр құралдың жеке нұсқауы бар: ҚМЖ, сабақ жоспары, БЖБ/ТЖБ, тест, көрнекілік, тәрбие сағаты және мектеп құжаттары. Тақырып өрісіне енді автоматты ішкі нұсқау жазылмайды — мұғалім өз нақты тапсырмасын жазады.

## Windows-та іске қосу
1. Node.js 20+ орнатыңыз.
2. `start-ustaziq.bat` файлын іске қосыңыз.
3. Бірінші рет `.env` ашылады. `OPENAI_API_KEY` жолына өз OpenAI API кілтіңізді енгізіңіз.
4. Браузерден `http://localhost:3000` ашылады.

## Қолдану мысалы
Пән: Қазақ тілі
Сынып: 3-сынып
Тақырып: Сын есім
Тапсырма: "Сын есім" тақырыбына 40 минуттық ҚМЖ жаса. 3 оқу тапсырмасы, жұптық жұмыс, жеке жұмыс, бағалау критерийлері, дескрипторлар, саралау, қауіпсіздік, рефлексия және үй тапсырмасы болсын.

## Маңызды
- API кілтін `.env` ішінде сақтаңыз; GitHub-қа `.env` жүктемеңіз.
- AI нәтижесін мектептің/оқу бағдарламасының нақты талаптарымен салыстырып тексеріңіз.
